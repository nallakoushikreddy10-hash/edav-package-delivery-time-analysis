# Package Delivery Time Analysis

EDAV (22ADC32N) Course-End Project - B.E. IT, III Semester, 2026-27
Chaitanya Bharathi Institute of Technology

## Objective
Analyze package delivery times to understand which factors drive late
deliveries and how delivery time varies by region, carrier, shipping
method, and season.

## Dataset
`Package_Delivery.csv` (source: add your dataset name and link here)

## Tools Used
- Python
- pandas, numpy
- matplotlib, seaborn

## What the Code Does
1. Loads and cleans the dataset (dates, numeric fields, missing values)
2. Creates features: delivery_days, delay_days, is_late, day_of_week, month
3. Produces visualizations: histogram, ECDF, boxplots, violin plot,
   monthly trend, heatmaps, scatterplots, correlation heatmap,
   late vs on-time comparison
4. Prints key findings

## How to Run
pip install pandas numpy matplotlib seaborn
python "Package Delivery Time Analysis.py"

Charts are saved in the `charts/` folder.
